# DPI Engine Dashboard

This React dashboard visualizes the JSON report generated by the DPI Engine and can trigger analysis runs through the Spring Boot REST API.

## Generate a report

Windows PowerShell:

```powershell
.\dpi_engine.exe test_dpi.pcap output.pcap --block-app YouTube --block-app TikTok --block-ip 192.168.1.50 --block-domain facebook --json-report frontend\dashboard\report.json
```

macOS/Linux:

```bash
./dpi_engine test_dpi.pcap output.pcap --block-app YouTube --block-app TikTok --block-ip 192.168.1.50 --block-domain facebook --json-report frontend/dashboard/report.json
```

## View the dashboard

From the `frontend/dashboard` directory:

```powershell
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

The dashboard tries to load `report.json` automatically. It also has an upload button for loading a JSON report manually.

## Run from website buttons

Start the Spring Boot REST API first:

```powershell
cd ..\..\backend\spring-api
mvn spring-boot:run
```

Then open the dashboard and use the preset buttons:

- Basic Analysis
- Block YouTube
- Block YouTube + TikTok
- Strict Security Mode
- High Throughput Mode

After each click, the dashboard updates the selected mode panel, active button,
blocking rules, thread settings, result strip, and charts from the API response.

Each button sends a `POST` request to:

```text
http://localhost:8080/api/analyze
```

The API runs `dpi_engine.exe`, generates a fresh JSON report, and returns it to the dashboard.
